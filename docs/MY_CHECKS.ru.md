## Как перенести это в декларацию

После выполнения своих проверок опиши их в `AI_DECLARATION.md`, используя конкретные результаты из этого файла. Если самостоятельно менял только текст или CSS, так и укажи. Если пока проверял приложение, но не менял код, можно описать только проверки. Для подтверждения понимания дополнительно разбери серверный код по `DEFENSE_GUIDE.ru.md`.
