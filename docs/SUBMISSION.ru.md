## 1. Зафиксировать сдаваемую версию

В терминале папки `Individual_Project/QuizForge`:

```sh
git status
git log --oneline -10
git rev-list --count HEAD
git rev-parse HEAD
git ls-remote --heads origin master
```

Рабочая папка должна быть чистой, число осмысленных коммитов — не менее 8. Хеш `HEAD` должен совпадать с хешем `master` на GitHub. Проверь доступ преподавателя к репозиторию. Сохрани полный хеш сдаваемой версии в комментарии к сдаче, если это предусмотрено формой.

## 2. Проверить запуск

```sh
npm install
npm test
npm start
```

Для чистой копии сначала создай `.env` по `.env.example` с собственным случайным `SESSION_SECRET`. Открой http://localhost:3000, пройди раунд и сверь результат с разбором. Дополнительные ручные проверки перечислены в `CHECKLIST.md`.

## 3. Завершить личные подтверждения

- Просмотри `AI_DECLARATION.md`: имя и ID заполнены, участие AI описано. Добавь только свои фактические проверки/правки и самостоятельно ответь на подтверждение понимания кода.
- Проверь, что API зарегистрирован, а proposal сдан, если это требуется отдельными этапами курса.
- Разбери код по `DEFENSE_GUIDE.ru.md` и потренируй небольшую правку.

## 4. Подготовить ZIP из этой же версии

Включи исходники приложения, `public/`, `views/`, `test/`, документацию, `package.json`, `package-lock.json`, `.env.example` и `.gitignore`.

Исключи `.env`, `node_modules/`, `.git/`, журналы запуска, временные файлы и другие архивы. После распаковки должны работать описанные в README установка и запуск. Сам архив готовится отдельным шагом; этот документ не подтверждает, что ZIP уже создан.

## 5. Отправить материалы

Передай ссылку на GitHub, финальный ZIP и декларацию в требуемые поля Canvas. Сверь актуальные сроки и список файлов с заданием. Сохрани подтверждение отправки и AI-переписку на срок, указанный в декларации.
